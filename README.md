## The Clinical Problem Solvers — Engineering

We build web tools and educational platforms supporting [The Clinical Problem Solvers](https://clinicalproblemsolving.com) and [CPS Academy](https://clinicalproblemsolving.com/academy/), helping medical students and clinicians worldwide master diagnostic reasoning.

**What we work on:**
- **CPS Academy Portal & Learning Tools** — interactive clinical reasoning and Virtual Morning Report workflows
- **Publishing & Scheduling Utilities** — internal tools supporting free global medical education

Most production repositories are currently private while under active development.
